# Datos sintéticos de prueba

Los tres archivos `objetos_detectados*.json` de este directorio son material
**sintético** usado para probar la interfaz. No provienen de SPHEREx, no son
resultado del pipeline y no deben citarse como datos científicos.

Son idénticos entre sí (mismo MD5 `836e6a66a05c55ec7efa228b41d3b07b`) y
contenían 1.391 registros de prueba. El catálogo científico real está en
`DATOS/real_residual_catalog.json` y se genera con `analysis/run_pipeline.py`.
